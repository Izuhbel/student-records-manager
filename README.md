# Student Records Manager

A beginner JavaScript project for managing and analysing student records.

## Overview

This project uses JavaScript to store student information, calculate grades, display student records and perform basic data analysis.

## Features

- Store student records using objects
- Display student information
- Calculate student grades
- Filter students based on their scores
- Extract student names
- Calculate the average score

## Concepts Practised

- Variables and functions
- Arrays and objects
- Conditional statements
- Loops
- Arrow functions
- Array methods: `forEach()`, `filter()` and `map()`
- Mathematical operations

## Built With

- JavaScript

## Getting Started

Run the program to explore how student records are stored, displayed, filtered and analysed using JavaScript.
